## What I maintain

### Stepik-Python-Grader

A local grader for Stepik Python courses that can:
- download task data automatically,
- run correctness checks locally,
- compare multiple solutions more honestly,
- rank results by correctness first and benchmark metrics second,
- and expose the workflow through CLI, local web UI, GUI launcher, and pytest integration.

It also goes beyond basic test execution:
- local glossary-linked error analysis,
- trace-based debugging with memory graph,
- subprocess benchmarking,
- optional OS-level sandboxing,
- AI failure explanations as an opt-in BYOK workflow,
- progress and history tracking,
- and contributor-facing docs split by user, dev, agent, and archive layers.
